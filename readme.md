# 🛍️ Proactive CX Dashboard for E-Commerce

This Streamlit app is designed to help e-commerce businesses proactively communicate with customers about delivery and refund delays — improving customer experience (CX), reducing escalations, and building trust.

## 🚀 Features

- **Real-Time Delay Detection**  
  Automatically flags delivery and refund delays using smart logic based on status, ETA, and communication history.

- **LLM-Powered Email Generation**  
  Uses a language model to craft empathetic, personalized apology emails with escalation details — tailored to each customer's order.

- **Interactive Dashboard**  
  Visual summaries of delay metrics, escalation counts, and agent performance — all wrapped in a lively, professional UI.

- **Session-State Driven UX**  
  Dynamic components like live status indicators, toggle buttons, and loading spinners for a responsive experience.

## 📦 Use Case

This app is ideal for operations, CX, and support teams in e-commerce who want to:

- Identify customer-impacting delays before complaints arise  
- Automate personalized communication using AI  
- Monitor refund and delivery performance daily  
- Reduce manual effort and improve resolution speed

## 🧰 Tech Stack

- [Streamlit](https://streamlit.io/) for UI  
- [LangChain](https://www.langchain.com/) or [LangGraph](https://docs.langgraph.xyz/) for agentic workflows  
- [OpenAI](https://platform.openai.com/) for LLM-powered messaging  
- Pandas for data processing
